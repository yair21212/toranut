# החלפות תורנויות

אתר להחלפת תורנויות מטבח בבסיס (שתפייה, חד"א, רמפה), בנוי ב־Expo (React Native Web) עם Supabase.

- כל אחד בוחר סוג תורנות, שם ומספר נייד (נשמר רק במכשיר).
- מפרסמים בקשה: היום שבו יש לי תורנות + ימים שמתאימים לי במקום (או "גמיש").
- רואים בקשות מאותו סוג, עם סימון "התאמה" כשהתאריכים מסתדרים.
- "הצעת החלפה" פותחת וואטסאפ מול האדם עם הודעה מוכנה.
- רק המכשיר שפרסם בקשה יכול להוריד אותה (טוקן סודי). בקשות שעבר התאריך שלהן נעלמות.

## פיתוח
```
npm install
npx expo start --web
```

## בנייה ופרסום (GitHub Pages)
```
npx expo export -p web
touch dist/.nojekyll && cp dist/index.html dist/404.html
```
את תוכן `dist` מעלים לענף `gh-pages`. נתיב הבסיס מוגדר ב־`app.json` (`experiments.baseUrl`).
