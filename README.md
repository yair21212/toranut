# החלפות תורנויות

אתר להחלפת תורנויות (שטפייה, חד"א, רמפה), בנוי ב־Expo (React Native Web) עם Supabase.

- כניסה עם סיסמה משותפת. כל אחד בוחר סוג תורנות, שם מלא ואימייל (להתחברות בלבד, לא מוצג).
- מפרסמים בקשה: היום שבו יש לי תורנות + ימים שמתאימים לי במקום (או "גמיש").
- רואים בקשות מאותו סוג, עם סימון "התאמה" כשהתאריכים מסתדרים.
- "הצעת החלפה" מעתיקה הודעה מוכנה ופותחת וואטסאפ, ומדביקים בצ׳אט של האדם.
- בקשה שייכת לאימייל או למכשיר שפרסם אותה. בקשות שעבר התאריך שלהן נעלמות.

## פיתוח
```
npm install
npx expo start --web
```

## בנייה ופרסום (GitHub Pages)
```
EXPO_BASE_URL=/toranut npx expo export -p web
touch dist/.nojekyll && cp dist/index.html dist/404.html
```
את תוכן `dist` מעלים לענף `gh-pages`. ב־Vercel הבנייה רצה אוטומטית (ראו `vercel.json`) והאתר מוגש מהשורש.
